검증 범위와 재현 조건

모든 글은 독립적으로 작성한 설명과 예제를 사용합니다. 시판 교재의 번역·전재·장별 재구성물이 아닙니다. 아래 공식 문서 링크를 각 주제의 근거로 제공합니다. 8.4·9.x 또는 MySQL 호환 제품에 동일한 동작을 자동 적용하지 마세요.

SQL 실습은 격리된 mysql_school 스키마를 사용합니다. DROP TABLE은 해당 학습 테이블만 초기화합니다. 운영 DB에서 실행하지 마세요. 실습 서버는 1편을 따라 한 번 준비하며, 여러 세션 실습은 실행 순서를 지켜야 합니다.

자동 검증은 HTML 구조·내부 링크·Q&A·대표 SQL 결과·RR/RC·잠금·데드락·정상 재시작·논리 백업 복원을 대상으로 구성했습니다. 실제 전원 차단 내구성, 운영 부하 성능, 저장장치별 페이지 압축 절감률, keyring 설치·키 회전·암호화 복원은 자동 검증 범위에 포함하지 않습니다. 해당 절에는 필요한 전제를 표시했습니다.
