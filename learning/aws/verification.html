AWS 시리즈 출처와 검증 범위

첨부 PDF 23개를 로드맵 1편·CORE 13편·심화 9편으로 대응해 한국어 해설을 작성했습니다. 원문 문장 전체의 번역본은 아니며 서비스 역할·설계 질문·실패 조건을 재구성했습니다. 원문 참고 링크와 반복 문구까지 모두 옮기지는 않았습니다.

근거와 범위

기준일은 2026-10-20입니다. 공개되지 않은 AWS 내부 구현은 단정하지 않습니다. App Mesh·Proton·OpsWorks·FinSpace 등의 제품 상태와 RDS 배포 형태·S3 일관성·SQS 재전달·IAM 권한 경계를 공식 문서와 대조했습니다. 수치 계산과 장애 상황은 학습용 예시입니다.

  • PDF 파일·쪽수·SHA-256·원문 제목 목록
  • 23편의 출처·분량·섹션·문답·공식 링크
  • 공식 링크 확인 기록
  • 구조·내부 링크·목차·문답·정책 JSON 검사
  • 전편 데스크톱·모바일 브라우저 검사

검증하지 않은 것

AWS 계정에서 리소스를 생성하거나 성능·장애·비용 실험을 실행하지 않았습니다. IAM 예시 JSON은 문법과 설명 범위를 확인한 정책 조각이며 실제 계정의 모든 정책 조합을 검증한 결과가 아닙니다. 웹 링크 확인은 조회 시점의 공식 페이지 접근과 관련성을 확인하는 작업이며 이후 변경을 보장하지 않습니다. GitHub 배포의 실제 성공 여부는 해당 커밋의 Actions 실행 기록과 공개 페이지로 확인합니다.
