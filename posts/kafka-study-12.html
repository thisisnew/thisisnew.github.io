12. Kafka의 주요 API 한눈에 보기

보내기, 받기, 관리하기는 각각 다른 일

공부 방법

비유 → 정확한 개념 → 내부 동작과 실제 사용 → 운영·장애 상황 순서로 읽어 보세요. 이해가 어려운 용어는 앞선 강의에서 다시 확인하면 좋습니다.

1. 다섯 살도 이해하는 비유

친구가 편지를 쓰는 일, 편지를 읽는 일, 게시판을 관리하는 일은 서로 달라요. Kafka도 작업마다 다른 API를 제공합니다.

2. 기초부터 정확하게 이해하기

Producer API는 전송, Consumer API는 수신, Admin API는 토픽·브로커 관리, Connect API는 외부 시스템 연계, Streams API는 스트림 변환을 담당합니다. Kafka 4.3 문서에는 Share Consumer API도 등장합니다.

3. 실제 시스템에서는?

Java에서는 kafka-clients 라이브러리를 통해 Producer, Consumer, AdminClient를 사용합니다. Kafka Streams와 Kafka Connect는 별도의 프로그램 구조·운영 개념을 가집니다.

4. 운영과 장애에서 기억할 점

업무 처리 서버에서 KafkaTemplate를 사용한다고 해서 Streams 애플리케이션을 운영 중인 것은 아닙니다. API 사용 범위를 구분하면 인프라 구성과 장애 대응이 명확해집니다.
