데이터센터 간 복제와 멀티테넌시

한 번에 외우려 하지 말고 비유와 실제 기술의 차이부터 읽어 보세요. 각 절은 동작 원리, 정상 처리, 장애 위험을 함께 설명합니다.

1. Geo Replication

5살도 이해하는 이야기

다른 도시에도 공지 복제 이 비유를 실제 기술로 연결해 보겠습니다.

정확한 내부 동작

데이터센터가 다른 클러스터에 레코드를 복제해 재해복구 또는 데이터 접근을 제공할 수 있다.

MirrorMaker 2 등 외부 복제 솔루션은 복제 지연을 갖는다.

언제 문제가 될까?

원본과 복제본 사이에 즉시 완전 일치를 가정하지 않는다.

🎯 확인 질문: Geo Replication의 동작과 장애 위험은?

정답: 데이터센터가 다른 클러스터에 레코드를 복제해 재해복구 또는 데이터 접근을 제공할 수 있다. MirrorMaker 2 등 외부 복제 솔루션은 복제 지연을 갖는다.

실무 포인트: 원본과 복제본 사이에 즉시 완전 일치를 가정하지 않는다.

2. Consumer 전환

5살도 이해하는 이야기

새 도서관에서 책갈피 찾기 이 비유를 실제 기술로 연결해 보겠습니다.

정확한 내부 동작

대상 클러스터에서 같은 Offset 숫자로 읽는 것이 항상 올바른 재개 지점은 아니다.

체크포인트 및 Offset Sync 방식을 검증해야 한다.

언제 문제가 될까?

전환 시 멱등성과 재처리 범위를 선언한다.

🎯 확인 질문: Consumer 전환의 동작과 장애 위험은?

정답: 대상 클러스터에서 같은 Offset 숫자로 읽는 것이 항상 올바른 재개 지점은 아니다. 체크포인트 및 Offset Sync 방식을 검증해야 한다.

실무 포인트: 전환 시 멱등성과 재처리 범위를 선언한다.

3. 멀티테넌시

5살도 이해하는 이야기

공용 건물에서 서로 다른 팀이 일함 이 비유를 실제 기술로 연결해 보겠습니다.

정확한 내부 동작

여러 서비스가 클러스터를 공유하면 Topic, ACL, Quota, 리소스 격리를 설계해야 한다.

한 서비스의 Producer 폭주가 공유 브로커에 영향을 줄 수 있다.

언제 문제가 될까?

프로젝트별 식별·접근·모니터링을 분리한다.

🎯 확인 질문: 멀티테넌시의 동작과 장애 위험은?

정답: 여러 서비스가 클러스터를 공유하면 Topic, ACL, Quota, 리소스 격리를 설계해야 한다. 한 서비스의 Producer 폭주가 공유 브로커에 영향을 줄 수 있다.

실무 포인트: 프로젝트별 식별·접근·모니터링을 분리한다.

4. 재해 복구 RPO/RTO

5살도 이해하는 이야기

얼마나 옛날 기록까지 허용? 언제 복구? 이 비유를 실제 기술로 연결해 보겠습니다.

정확한 내부 동작

RPO는 허용 가능한 데이터 손실 시점, RTO는 허용 가능한 복구 시간 목표다.

복제 지연과 전환 절차를 실제 시험해야 요구치를 만족하는지 알 수 있다.

언제 문제가 될까?

훈련 없이 DR이 된다고 주장하지 않는다.

🎯 확인 질문: 재해 복구 RPO/RTO의 동작과 장애 위험은?

정답: RPO는 허용 가능한 데이터 손실 시점, RTO는 허용 가능한 복구 시간 목표다. 복제 지연과 전환 절차를 실제 시험해야 요구치를 만족하는지 알 수 있다.

실무 포인트: 훈련 없이 DR이 된다고 주장하지 않는다.
