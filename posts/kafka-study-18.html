18. Kafka 통신 프로토콜 입문

컴퓨터끼리는 어떤 말로 이야기할까?

공부 방법

비유 → 정확한 개념 → 내부 동작과 실제 사용 → 운영·장애 상황 순서로 읽어 보세요. 이해가 어려운 용어는 앞선 강의에서 다시 확인하면 좋습니다.

1. 다섯 살도 이해하는 비유

한국어와 영어를 쓰는 친구가 대화하려면 서로 이해할 수 있는 표현 방식이 필요해요. Kafka Client와 Broker도 규칙이 있습니다.

2. 기초부터 정확하게 이해하기

Kafka는 TCP 위에서 바이너리 요청·응답 프로토콜을 사용합니다. 각 요청에는 API Key와 Version 등이 있어 어떤 요청인지와 메시지 구조를 구분합니다.

3. 실제 시스템에서는?

클라이언트는 브로커와 지원하는 버전 범위를 조합해 통신합니다. 프로토콜 버전이 맞지 않으면 새로운 필드를 이해하지 못하거나 지원되지 않는 요청 에러가 발생할 수 있습니다.

4. 운영과 장애에서 기억할 점

API Key, Correlation ID, 요청 헤더, 응답 에러 코드를 구분하고 패킷을 진단할 때는 TLS 암호화 사용 여부도 고려하세요.
