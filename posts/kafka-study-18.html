1. 요청·응답 프레임

5살도 이해하는 이야기

전화할 때 말의 순서를 정하는 규칙 이 비유를 실제 기술로 연결해 보겠습니다.

정확한 내부 동작

Kafka 클라이언트와 Broker는 TCP 위에서 요청 헤더, 요청 본문, 응답 헤더, 응답 본문을 주고받는다.

API Key는 작업 종류, API Version은 해당 작업의 메시지 구조 버전을 뜻한다.

언제 문제가 될까?

브로커 API와 Kafka Java 메서드의 이름을 동일시하지 않는다.

실무 포인트: 브로커 API와 Kafka Java 메서드의 이름을 동일시하지 않는다.

2. Correlation ID

5살도 이해하는 이야기

편지와 답장의 접수번호 이 비유를 실제 기술로 연결해 보겠습니다.

정확한 내부 동작

한 연결에 여러 요청이 있을 때 응답을 원래 요청과 연결하기 위한 식별자이다.

요청 로그에 correlation id를 남기면 어떤 요청의 결과인지 추적하기 쉽다.

언제 문제가 될까?

느린 응답과 재시도로 인한 중복 전송 가능성을 구분한다.

🎯 확인 질문: Correlation ID의 동작과 장애 위험은?

정답: 한 연결에 여러 요청이 있을 때 응답을 원래 요청과 연결하기 위한 식별자이다. 요청 로그에 correlation id를 남기면 어떤 요청의 결과인지 추적하기 쉽다.

실무 포인트: 느린 응답과 재시도로 인한 중복 전송 가능성을 구분한다.

3. ApiVersions

5살도 이해하는 이야기

서로 이해할 수 있는 언어 확인 이 비유를 실제 기술로 연결해 보겠습니다.

정확한 내부 동작

클라이언트는 브로커가 지원하는 API 버전을 파악해 호환 가능한 형식으로 요청할 수 있다.

새 Broker가 모든 오래된 클라이언트 기능을 무조건 지원하는 것은 아니므로 지원 범위가 중요하다.

언제 문제가 될까?

브로커·클라이언트 교체 전에 호환성을 검증한다.

🎯 확인 질문: ApiVersions의 동작과 장애 위험은?

정답: 클라이언트는 브로커가 지원하는 API 버전을 파악해 호환 가능한 형식으로 요청할 수 있다. 새 Broker가 모든 오래된 클라이언트 기능을 무조건 지원하는 것은 아니므로 지원 범위가 중요하다.

실무 포인트: 브로커·클라이언트 교체 전에 호환성을 검증한다.

4. 오류 코드와 재시도

5살도 이해하는 이야기

문이 잠긴 것과 길이 막힌 것은 다름 이 비유를 실제 기술로 연결해 보겠습니다.

정확한 내부 동작

리더 이동 같은 일시적 오류와 인증·인가·스키마 오류는 복구 방법이 다르다.

에러 코드 및 재시도 가능 여부를 버전별 공식 프로토콜에서 확인한다.

언제 문제가 될까?

모든 오류를 무한 재시도하면 장애가 악화된다.

🎯 확인 질문: 오류 코드와 재시도의 동작과 장애 위험은?

정답: 리더 이동 같은 일시적 오류와 인증·인가·스키마 오류는 복구 방법이 다르다. 에러 코드 및 재시도 가능 여부를 버전별 공식 프로토콜에서 확인한다.

실무 포인트: 모든 오류를 무한 재시도하면 장애가 악화된다.
