14. Kafka Connect 설정을 이해하기

다른 창고와 데이터를 주고받자

공부 방법

비유 → 정확한 개념 → 내부 동작과 실제 사용 → 운영·장애 상황 순서로 읽어 보세요. 이해가 어려운 용어는 앞선 강의에서 다시 확인하면 좋습니다.

1. 다섯 살도 이해하는 비유

마을 창고와 다른 마을 창고가 물건을 옮겨야 한다면 전담 배송 차량을 운영할 수 있어요. Kafka Connect는 데이터 이동을 반복적으로 실행하는 틀입니다.

2. 기초부터 정확하게 이해하기

Source Connector는 외부 데이터 소스에서 Kafka로, Sink Connector는 Kafka에서 외부 대상으로 데이터를 옮깁니다. Connector가 전체 작업을 설명하고 Task가 실제 병렬 작업을 수행합니다.

3. 실제 시스템에서는?

Worker는 Connect 실행 프로세스이고 standalone 또는 distributed 모드로 운영할 수 있습니다. converter는 Kafka 레코드와 Connect 데이터 모델 간 변환을 담당하며, key/value converter를 구분합니다.

4. 운영과 장애에서 기억할 점

커넥터 설정이 맞더라도 외부 DB 접근 권한, 스키마 진화, 토픽 파티션 수, 재시도, 오류 기록, DLQ 전략이 잘못되면 운영 장애가 발생합니다.
