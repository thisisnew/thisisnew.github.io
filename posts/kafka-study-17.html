17. Tiered Storage와 설정 제공자

오래된 자료는 다른 창고에

공부 방법

비유 → 정확한 개념 → 내부 동작과 실제 사용 → 운영·장애 상황 순서로 읽어 보세요. 이해가 어려운 용어는 앞선 강의에서 다시 확인하면 좋습니다.

1. 다섯 살도 이해하는 비유

자주 읽는 책은 책상 옆에 놓고 오래된 책은 창고로 옮겨도 돼요. Tiered Storage는 오래된 로그를 원격 저장소로 확장합니다.

2. 기초부터 정확하게 이해하기

브로커의 로컬 저장 공간과 원격 계층을 함께 사용하는 구조입니다. 사용 중인 Kafka 버전과 스토리지 플러그인 구현이 지원하는 정책과 제약을 확인해야 합니다.

3. 실제 시스템에서는?

Configuration Provider는 설정 값의 일부를 외부 소스에서 읽어오도록 돕습니다. 비밀번호 같은 값을 코드에 직접 박는 것보다 관리하기 좋지만 비밀 정보 접근 제어는 여전히 필요합니다.

4. 운영과 장애에서 기억할 점

원격 저장소를 쓰면 비용이 무조건 줄어드는 것은 아닙니다. 전송 비용, 재조회 지연, 보관 정책, 가용성, 복구 실험을 함께 검증하세요.
