Tiered Storage와 외부 설정 제공자

한 번에 외우려 하지 말고 비유와 실제 기술의 차이부터 읽어 보세요. 각 절은 동작 원리, 정상 처리, 장애 위험을 함께 설명합니다.

1. 로컬 로그와 원격 계층

5살도 이해하는 이야기

당장 볼 책은 책상에, 오래된 책은 창고에 이 비유를 실제 기술로 연결해 보겠습니다.

정확한 내부 동작

Tiered Storage는 오래된 로그를 원격 저장계층으로 옮기고 필요할 때 읽게 하는 접근이다.

세그먼트 단위의 로컬 보존·원격 보존 및 fetch 경로를 분리해 이해해야 한다.

언제 문제가 될까?

원격 저장소 장애가 과거 데이터 재조회에 영향을 줄 수 있다.

실무 포인트: 원격 저장소 장애가 과거 데이터 재조회에 영향을 줄 수 있다.

2. 보존기간과 비용

5살도 이해하는 이야기

책장 공간은 줄지만 배달비는 늘 수 있음 이 비유를 실제 기술로 연결해 보겠습니다.

정확한 내부 동작

원격 데이터에도 retention과 삭제 주기가 있고 스토리지 비용뿐 아니라 다운로드·API 비용이 있다.

접근 패턴, 복구 목표 시간, 원격 조회 지연을 기준으로 비용을 비교한다.

언제 문제가 될까?

원격 보존은 모든 재처리 요청이 즉시 빠르다는 뜻이 아니다.

🎯 확인 질문: 보존기간과 비용의 동작과 장애 위험은?

정답: 원격 데이터에도 retention과 삭제 주기가 있고 스토리지 비용뿐 아니라 다운로드·API 비용이 있다. 접근 패턴, 복구 목표 시간, 원격 조회 지연을 기준으로 비용을 비교한다.

실무 포인트: 원격 보존은 모든 재처리 요청이 즉시 빠르다는 뜻이 아니다.

3. Remote Storage Manager

5살도 이해하는 이야기

창고 직원이 어느 서류를 어디로 옮길지 관리 이 비유를 실제 기술로 연결해 보겠습니다.

정확한 내부 동작

원격 스토리지 제공자 구현은 로그 세그먼트 복사·조회·삭제와 관련된다.

사용 중인 배포판이 어떤 플러그인을 실제 지원하는지 확인한다.

언제 문제가 될까?

제공자가 없는 환경에서 옵션만 켠다고 저장소가 생기지 않는다.

🎯 확인 질문: Remote Storage Manager의 동작과 장애 위험은?

정답: 원격 스토리지 제공자 구현은 로그 세그먼트 복사·조회·삭제와 관련된다. 사용 중인 배포판이 어떤 플러그인을 실제 지원하는지 확인한다.

실무 포인트: 제공자가 없는 환경에서 옵션만 켠다고 저장소가 생기지 않는다.

4. ConfigProvider

5살도 이해하는 이야기

비밀번호를 공개 공책 대신 보관함에서 읽기 이 비유를 실제 기술로 연결해 보겠습니다.

정확한 내부 동작

외부 설정 제공자는 설정의 일부 값을 외부 파일 또는 비밀 관리 소스에서 읽도록 돕는다.

설정 문자열 참조와 값 로딩 시점, 접근 권한을 구분한다.

언제 문제가 될까?

비밀값이 로그·Git 기록에 남지 않도록 점검한다.

🎯 확인 질문: ConfigProvider의 동작과 장애 위험은?

정답: 외부 설정 제공자는 설정의 일부 값을 외부 파일 또는 비밀 관리 소스에서 읽도록 돕는다. 설정 문자열 참조와 값 로딩 시점, 접근 권한을 구분한다.

실무 포인트: 비밀값이 로그·Git 기록에 남지 않도록 점검한다.
