3. SSL/TLS

5살도 이해하는 이야기

봉투에 자물쇠를 채워 전달 이 비유를 실제 기술로 연결해 보겠습니다.

정확한 내부 동작

TLS는 전송 구간 암호화와 서버 인증서 검증을 제공한다.

서버 인증서의 SAN과 접속 호스트명, truststore를 확인해야 한다.

언제 문제가 될까?

인증서 만료 날짜와 갱신 배포를 감시한다.

🎯 확인 질문: SSL/TLS의 동작과 장애 위험은?

정답: TLS는 전송 구간 암호화와 서버 인증서 검증을 제공한다. 서버 인증서의 SAN과 접속 호스트명, truststore를 확인해야 한다.

실무 포인트: 인증서 만료 날짜와 갱신 배포를 감시한다.

4. mTLS

5살도 이해하는 이야기

양쪽이 서로 신분증 확인 이 비유를 실제 기술로 연결해 보겠습니다.

정확한 내부 동작

클라이언트 인증서 검증을 요구하는 설정이면 클라이언트도 자신의 인증서를 제공한다.

TLS 암호화와 SASL 인증은 목적이 겹치지만 동일한 개념은 아니다.

언제 문제가 될까?

클라이언트 인증 방식과 Topic ACL을 분리한다.

실무 포인트: 클라이언트 인증 방식과 Topic ACL을 분리한다.
