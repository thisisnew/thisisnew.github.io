Processor API와 Serde 심화

도트 게임 속 스테이지를 진행하듯, 쉬운 비유부터 기술적인 흐름과 장애 대응을 함께 익혀봅시다. 비유의 한계를 기억하고 실제 용어를 직접 설명해 보세요.

1. Processor API

처음 듣는 사람을 위한 비유

기성 공구 대신 맞춤형 공구

정확한 개념과 내부 동작

Processor API는 DSL에서 표현하기 어려운 레코드 단위 처리와 State Store 접근을 구성하는 저수준 API다.

실무에서 생기는 문제

직접 상태·시간·복구를 다루므로 테스트 부담이 증가한다.

🎯 연습 문제: Processor API을(를) 설명해 보세요.

정답: Processor API는 DSL에서 표현하기 어려운 레코드 단위 처리와 State Store 접근을 구성하는 저수준 API다. 직접 상태·시간·복구를 다루므로 테스트 부담이 증가한다.

2. Serde

처음 듣는 사람을 위한 비유

한국어와 바이트 언어 번역기

정확한 개념과 내부 동작

Serializer는 객체→바이트, Deserializer는 바이트→객체이며 Serde는 둘의 조합이다.

실무에서 생기는 문제

Schema Evolution과 역직렬화 오류 정책을 확인한다.

🎯 연습 문제: Serde을(를) 설명해 보세요.

정답: Serializer는 객체→바이트, Deserializer는 바이트→객체이며 Serde는 둘의 조합이다. Schema Evolution과 역직렬화 오류 정책을 확인한다.

3. State Store

처음 듣는 사람을 위한 비유

상태를 기록하는 공책

정확한 개념과 내부 동작

프로세서가 상태를 읽고 변경할 수 있으나 재배치와 복구를 고려해야 한다.

실무에서 생기는 문제

로컬 저장소만 믿고 Changelog 복구 설계를 생략하지 않는다.

🎯 연습 문제: State Store을(를) 설명해 보세요.

정답: 프로세서가 상태를 읽고 변경할 수 있으나 재배치와 복구를 고려해야 한다. 로컬 저장소만 믿고 Changelog 복구 설계를 생략하지 않는다.

4. Punctuation

처음 듣는 사람을 위한 비유

일정 시간마다 종 치기

정확한 개념과 내부 동작

일정한 간격으로 처리를 실행하는 방법이 있고 Stream-time과 Wall-clock-time의 차이를 이해해야 한다.

실무에서 생기는 문제

메시지가 멈췄을 때 Stream-time 기반 동작도 멈출 수 있다.

🎯 연습 문제: Punctuation을(를) 설명해 보세요.

정답: 일정한 간격으로 처리를 실행하는 방법이 있고 Stream-time과 Wall-clock-time의 차이를 이해해야 한다. 메시지가 멈췄을 때 Stream-time 기반 동작도 멈출 수 있다.

실습과 점검

테스트 토픽과 격리된 Kafka 클러스터에서 각각의 이벤트 Key, Partition, Offset, 처리 성공 여부를 기록하며 결과를 추적하세요. 상태를 사용하는 기능은 앱 재시작 시 복구 시간도 측정합니다. 운영 클러스터의 오프셋을 임의로 수정하거나 Topic을 삭제해서는 안 됩니다.
