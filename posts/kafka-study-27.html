27. Kafka Connect 처음부터 사용하기

코드를 매번 쓰지 않고 데이터 이동하기

공부 방법

비유 → 정확한 개념 → 내부 동작과 실제 사용 → 운영·장애 상황 순서로 읽어 보세요. 이해가 어려운 용어는 앞선 강의에서 다시 확인하면 좋습니다.

1. 다섯 살도 이해하는 비유

이웃 학교로 같은 물건을 자주 보내야 한다면 전담 운반 체계가 편리해요. Connect는 반복 데이터 이동 작업의 기반을 제공합니다.

2. 기초부터 정확하게 이해하기

Source Connector는 DB·로그 등의 외부 데이터에서 Kafka로 읽어오고 Sink Connector는 Kafka 데이터를 외부 저장소로 내보냅니다. Connector는 설정 단위, Task는 실제 실행 단위입니다.

3. 실제 시스템에서는?

Distributed Worker는 내부 토픽에 설정과 상태를 저장하며 REST API로 Connectors를 관리할 수 있습니다. 필요한 내부 토픽과 리플리케이션 요건을 사전에 점검하세요.

4. 운영과 장애에서 기억할 점

처리 실패 시 Connector와 Task의 상태를 분리해 보세요. 외부 시스템의 요청 제한이나 일시 장애로 Task만 실패하는 경우도 있습니다.
