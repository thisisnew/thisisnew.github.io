Connect User Guide: 실제 연결 흐름

도트 게임 속 스테이지를 진행하듯, 쉬운 비유부터 기술적인 흐름과 장애 대응을 함께 익혀봅시다. 비유의 한계를 기억하고 실제 용어를 직접 설명해 보세요.

1. Source Connector

처음 듣는 사람을 위한 비유

외부 창고에서 메시지를 가져오는 차량

정확한 개념과 내부 동작

Source Connector는 외부 소스에서 데이터와 소스 진행 위치를 가져와 Kafka 레코드로 전환한다.

실무에서 생기는 문제

CDC 도입 시 원본 DB 접근 권한, 초기 스냅샷 및 변경 로그 보관 정책을 확인한다.

🎯 연습 문제: Source Connector을(를) 설명해 보세요.

정답: Source Connector는 외부 소스에서 데이터와 소스 진행 위치를 가져와 Kafka 레코드로 전환한다. CDC 도입 시 원본 DB 접근 권한, 초기 스냅샷 및 변경 로그 보관 정책을 확인한다.

2. Sink Connector

처음 듣는 사람을 위한 비유

Kafka에서 외부 창고로 나르는 차량

정확한 개념과 내부 동작

Sink Connector는 Kafka 토픽에서 읽은 데이터를 외부 저장소로 전달한다.

실무에서 생기는 문제

외부 DB 삽입 실패 후 재시도 시 중복 갱신 가능성에 대비한다.

🎯 연습 문제: Sink Connector을(를) 설명해 보세요.

정답: Sink Connector는 Kafka 토픽에서 읽은 데이터를 외부 저장소로 전달한다. 외부 DB 삽입 실패 후 재시도 시 중복 갱신 가능성에 대비한다.

3. Worker와 Task

처음 듣는 사람을 위한 비유

운송회사와 실제 운전기사

정확한 개념과 내부 동작

Distributed Worker는 Connector 설정·상태와 Task 실행을 협력해 관리한다.

실무에서 생기는 문제

Task 수 증가가 외부 시스템의 최대 동시 처리 수를 넘지 않도록 한다.

🎯 연습 문제: Worker와 Task을(를) 설명해 보세요.

정답: Distributed Worker는 Connector 설정·상태와 Task 실행을 협력해 관리한다. Task 수 증가가 외부 시스템의 최대 동시 처리 수를 넘지 않도록 한다.

4. Transform과 Converter

처음 듣는 사람을 위한 비유

운송 전에 포장과 번역

정확한 개념과 내부 동작

SMT는 개별 Record의 간단한 필드 변환, Converter는 Connect 데이터와 외부 Kafka 레코드 형식 변환에 사용된다.

실무에서 생기는 문제

복잡한 비즈니스 트랜잭션을 SMT 하나에 모두 넣지 않는다.

🎯 연습 문제: Transform과 Converter을(를) 설명해 보세요.

정답: SMT는 개별 Record의 간단한 필드 변환, Converter는 Connect 데이터와 외부 Kafka 레코드 형식 변환에 사용된다. 복잡한 비즈니스 트랜잭션을 SMT 하나에 모두 넣지 않는다.

실습과 점검

테스트 토픽과 격리된 Kafka 클러스터에서 각각의 이벤트 Key, Partition, Offset, 처리 성공 여부를 기록하며 결과를 추적하세요. 상태를 사용하는 기능은 앱 재시작 시 복구 시간도 측정합니다. 운영 클러스터의 오프셋을 임의로 수정하거나 Topic을 삭제해서는 안 됩니다.
