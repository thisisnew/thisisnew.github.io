Streams 테스트·쿼리·메모리

도트 게임 속 스테이지를 진행하듯, 쉬운 비유부터 기술적인 흐름과 장애 대응을 함께 익혀봅시다. 비유의 한계를 기억하고 실제 용어를 직접 설명해 보세요.

1. TopologyTestDriver

처음 듣는 사람을 위한 비유

작은 공장 모형에 재료를 넣어 실험

정확한 개념과 내부 동작

실제 Broker 없이 토폴로지에 테스트 레코드를 넣어 결과를 검증할 수 있다.

실무에서 생기는 문제

시간 창과 늦은 이벤트는 시간 입력을 명시적으로 테스트한다.

🎯 연습 문제: TopologyTestDriver을(를) 설명해 보세요.

정답: 실제 Broker 없이 토폴로지에 테스트 레코드를 넣어 결과를 검증할 수 있다. 시간 창과 늦은 이벤트는 시간 입력을 명시적으로 테스트한다.

2. Interactive Queries

처음 듣는 사람을 위한 비유

지역 공장 장부 열람

정확한 개념과 내부 동작

상태 저장소를 가진 Streams 인스턴스의 로컬 상태를 조회할 수 있다.

실무에서 생기는 문제

분산된 다른 인스턴스의 상태까지 자동으로 한 API에서 모으는 것은 아니다.

🎯 연습 문제: Interactive Queries을(를) 설명해 보세요.

정답: 상태 저장소를 가진 Streams 인스턴스의 로컬 상태를 조회할 수 있다. 분산된 다른 인스턴스의 상태까지 자동으로 한 API에서 모으는 것은 아니다.

3. State Store 디스크

처음 듣는 사람을 위한 비유

공책이 많아지면 보관함 필요

정확한 개념과 내부 동작

상태 저장 집계량이 많으면 로컬 디스크·복구 대역폭이 병목이 될 수 있다.

실무에서 생기는 문제

Task 이동과 재시작 시간, Standby 복제 비용을 측정한다.

🎯 연습 문제: State Store 디스크을(를) 설명해 보세요.

정답: 상태 저장 집계량이 많으면 로컬 디스크·복구 대역폭이 병목이 될 수 있다. Task 이동과 재시작 시간, Standby 복제 비용을 측정한다.

4. 이벤트 시간

처음 듣는 사람을 위한 비유

도착한 시각과 발생한 시각은 다름

정확한 개념과 내부 동작

Timestamp Extractor 정책과 Window의 시간 의미가 결과에 영향을 준다.

실무에서 생기는 문제

도착이 늦거나 역순인 이벤트에 대한 테스트를 추가한다.

🎯 연습 문제: 이벤트 시간을(를) 설명해 보세요.

정답: Timestamp Extractor 정책과 Window의 시간 의미가 결과에 영향을 준다. 도착이 늦거나 역순인 이벤트에 대한 테스트를 추가한다.

실습과 점검

테스트 토픽과 격리된 Kafka 클러스터에서 각각의 이벤트 Key, Partition, Offset, 처리 성공 여부를 기록하며 결과를 추적하세요. 상태를 사용하는 기능은 앱 재시작 시 복구 시간도 측정합니다. 운영 클러스터의 오프셋을 임의로 수정하거나 Topic을 삭제해서는 안 됩니다.
