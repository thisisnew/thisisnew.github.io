11. Kafka 업그레이드와 KRaft 마이그레이션

버전이 바뀌면 왜 조심해야 할까?

공부 방법

비유 → 정확한 개념 → 내부 동작과 실제 사용 → 운영·장애 상황 순서로 읽어 보세요. 이해가 어려운 용어는 앞선 강의에서 다시 확인하면 좋습니다.

1. 다섯 살도 이해하는 비유

게임 규칙이 달라질 때 모든 친구가 새 규칙을 동시에 외우지 않아도 게임이 이어져야 해요. Kafka 업그레이드도 클라이언트·브로커 간 호환성이 핵심입니다.

2. 기초부터 정확하게 이해하기

Kafka 업그레이드는 실행 파일 교체만이 아닙니다. 현재 버전, 지원되는 중간 업그레이드 경로, metadata.version, 클라이언트 프로토콜 호환성, KRaft 전환 여부를 확인해야 합니다.

3. 실제 시스템에서는?

롤링 업그레이드에서는 브로커를 한 번에 모두 내리지 않고 차례대로 재시작합니다. 이때 ISR 감소, 파티션 리더 변화, 컨트롤러 상태, 생산·소비 에러를 감시합니다.

4. 운영과 장애에서 기억할 점

스테이징에서 실제 Producer·Consumer 버전 조합으로 검증하고, 롤백 가능 시점을 명시하세요. KRaft 전환 가능 경로는 Kafka 버전별 공식 절차를 반드시 확인해야 합니다.
