15. Kafka Streams 애플리케이션 설정

흐르는 물을 걸러내는 체

공부 방법

비유 → 정확한 개념 → 내부 동작과 실제 사용 → 운영·장애 상황 순서로 읽어 보세요. 이해가 어려운 용어는 앞선 강의에서 다시 확인하면 좋습니다.

1. 다섯 살도 이해하는 비유

강에서 흐르는 물을 체로 걸러 필요한 것만 모을 수 있어요. Streams는 Kafka 이벤트가 이동하는 도중 변환하고 집계합니다.

2. 기초부터 정확하게 이해하기

application.id는 Streams 애플리케이션 식별 및 내부 리소스 관리와 연결됩니다. bootstrap.servers는 클러스터에 연결하기 위한 초기 브로커 주소입니다. processing.guarantee는 처리 보장 설정에 영향을 줍니다.

3. 실제 시스템에서는?

상태 저장 연산은 로컬 state store와 changelog 토픽을 활용할 수 있습니다. 재시작 시 상태 복구 시간을 고려하고, RocksDB 디스크 사용량과 내부 토픽 복제를 확인해야 합니다.

4. 운영과 장애에서 기억할 점

Streams 구성은 단순 소비 후 비즈니스 서비스 호출과 다릅니다. 토폴로지, 상태 저장소, repartition, 내부 토픽, 재밸런싱까지 운영 대상에 포함됩니다.
