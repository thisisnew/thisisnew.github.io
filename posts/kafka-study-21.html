관리 프로토콜의 요청과 응답

2. AlterConfigs

5살도 이해하는 이야기

게시판 규칙 수정 이 비유를 실제 기술로 연결해 보겠습니다.

정확한 내부 동작

관리 요청은 설정 변경 대상을 지정하고 변경 가능 여부와 권한을 검증한다.

동적 수정 가능한 설정과 노드 재시작이 필요한 설정은 다르다.

언제 문제가 될까?

변경 전 설정 스냅샷과 롤백 계획이 필요하다.

🎯 확인 질문: AlterConfigs의 동작과 장애 위험은?

정답: 관리 요청은 설정 변경 대상을 지정하고 변경 가능 여부와 권한을 검증한다. 동적 수정 가능한 설정과 노드 재시작이 필요한 설정은 다르다.

실무 포인트: 변경 전 설정 스냅샷과 롤백 계획이 필요하다.

3. DescribeGroups

5살도 이해하는 이야기

모둠 구성 확인 이 비유를 실제 기술로 연결해 보겠습니다.

정확한 내부 동작

그룹 상태와 멤버 정보를 조회해 소비 장애를 진단한다.

그룹이 보이는 것만으로 비즈니스 처리가 성공했다는 의미는 아니다.

언제 문제가 될까?

Commit 지표·처리 성공률·할당을 함께 비교한다.

🎯 확인 질문: DescribeGroups의 동작과 장애 위험은?

정답: 그룹 상태와 멤버 정보를 조회해 소비 장애를 진단한다. 그룹이 보이는 것만으로 비즈니스 처리가 성공했다는 의미는 아니다.

실무 포인트: Commit 지표·처리 성공률·할당을 함께 비교한다.

4. 권한 관련 응답

5살도 이해하는 이야기

교실 문을 열 열쇠가 없음 이 비유를 실제 기술로 연결해 보겠습니다.

정확한 내부 동작

인증과 인가는 분리되어 있으며 Topic Read, Write, Group 권한이 동작별로 필요하다.

실제 API Error를 보고 ACL 부족인지 인증 실패인지 구분한다.

언제 문제가 될까?

동일한 오류 코드만 반복 재시도하지 않는다.

🎯 확인 질문: 권한 관련 응답의 동작과 장애 위험은?

정답: 인증과 인가는 분리되어 있으며 Topic Read, Write, Group 권한이 동작별로 필요하다. 실제 API Error를 보고 ACL 부족인지 인증 실패인지 구분한다.

실무 포인트: 동일한 오류 코드만 반복 재시도하지 않는다.
